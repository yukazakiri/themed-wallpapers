# Themed Wallpapers

Pre-themed wallpapers using [gowall](https://github.com/xyph3r/gowall).

## Installation

### One-liner install specific theme:

```bash
curl -sL https://github.com/yukazakiri/themed-wallpapers/archive/refs/heads/master.tar.gz | tar xz -C ~/Pictures/ThemedWallpapers --strip-components=1
```

Or clone the repository:

```bash
git clone https://github.com/yukazakiri/themed-wallpapers.git ~/Pictures/ThemedWallpapers
```
